# Breakout wiki

**English** · [Dansk](Home-da) · [Bahasa Malaysia](Home-ms)

A clone of the 1976 arcade game Breakout, built with Python Turtle as the Day 87 assignment of the Udemy course "100 Days of Code: The Complete Python Pro Bootcamp". The game has a paddle, a ball, a wall of coloured bricks, a score, three lives and a win or game over.

The project was built in seven steps. Every step has a screenshot and a page that explains what we built and what we gained from it.

## About the code

- Python 3.13 or newer, standard library only: the game has no runtime dependency.
- Game rules are pure Python and tested with pytest; Turtle is only used to draw.
- The wiki exists in English, Danish and Bahasa Malaysia.

The source, the README and the issue tracker are in the [repository](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/087-assignment-breakout-game).
