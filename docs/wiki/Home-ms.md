# Wiki Breakout

[English](Home) · [Dansk](Home-da) · **Bahasa Malaysia**

Klon permainan arked Breakout dari tahun 1976, dibina dengan Python Turtle sebagai tugasan Hari ke-87 kursus Udemy "100 Days of Code: The Complete Python Pro Bootcamp". Permainan ini mempunyai dayung, bola, dinding bata berwarna, skor, tiga nyawa dan kemenangan atau permainan tamat.

Projek ini dibina dalam tujuh langkah. Setiap langkah mempunyai tangkapan skrin dan satu halaman yang menerangkan apa yang kami bina dan apa yang kami peroleh daripadanya.

## Tentang kod

- Python 3.13 atau lebih baharu, pustaka standard sahaja: permainan tidak mempunyai kebergantungan masa jalan.
- Peraturan permainan ialah Python tulen dan diuji dengan pytest; Turtle hanya digunakan untuk melukis.
- Wiki ini wujud dalam bahasa Inggeris, Denmark dan Bahasa Malaysia.

Kod sumber, README dan penjejak isu terdapat dalam [repositori](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/087-assignment-breakout-game).
